# 发布文案规范（抖音 / 小红书）

完整样张：`assets/share-copy.template.md`（第 01 课实测版）。
写文案时**只许复用课程 JSON 里已有的句子**，不许自己编新英语表达——文案与课件不一致会毁信任。

## 平台差异

| | 抖音 | 小红书 |
|---|---|---|
| 目的 | 3 秒钩住，靠痛点+数字留人 | 被收藏，靠"这一篇就够了" |
| 结构 | 封面 3 行大字 + 30s 口播脚本 | 标题 + emoji 分段正文 + 标签 |
| 语感 | 口语、短句、有停顿感 | 分享腔、有温度、像朋友整理 |
| 封面 | `NN_封面_3x4.png` | `NN_封面_3x4.png`（首图） |
| 引导 | 评论区扣关键词领资料 | 收藏 + 评论区互动提问 |

## 抖音模板

- **封面 3 行大字**：第 1 行场景，第 2 行数字承诺，第 3 行代价/收益。
  例：`入境美国` / `只用这 5 句` / `海关问什么答什么`。
- **标题 3 选 1**：痛点型 / 数字型 / 故事型，都要带 1 个 emoji。
- **话题标签**：4 个泛词（#英语学习 #生活英语）+ 3 个精准词（#美国入境 #海关英语）。
- **30 秒口播脚本**：分镜表（时间 / 台词）。节奏是
  `0-3s 钩子 → 3-8s 承诺 → 8-24s 干货（5 组问答点名） → 24-30s 引导评论区`。
- **发布建议**：时间（工作日 12-13 点或 20-22 点）、置顶评论（怎么领资料）、结尾提问。

## 小红书模板

- **标题（≤20 字）**：场景 + 数字 + 结果，配 1-2 个 emoji。
  例：`入境美国海关只问这5句｜背完直接过✅`
- **正文分段**（每段一个 emoji）：
  1. 开场一句共情（"落地美国，真正的第一关是海关那 30 秒😨"）
  2. 必背 N 组问答（编号 + 英文 + 中文 + 一句注意点）
  3. 雷区提醒（3 条，语气像提醒朋友）
  4. 先记这 N 个词 + 一句总结
  5. 互动钩子 + 怎么拿资料
- **话题标签**：8-10 个，泛词与精准词混排。
- **封面指引**：直接引用生成的封面图文件名，并说明该用哪张比例。

## 发布节奏

| 平台 | 形式 | 素材 |
|---|---|---|
| 抖音 | 30s 竖版切片 | 口播脚本 + 3:4 封面（引流） |
| 抖音 | 完整版 | 讲解视频 6-8 分钟 |
| 小红书 | 图文笔记 | 3:4 封面首图 + 资料卡片 PDF 截 3 页 |
| 小红书 | 视频笔记 | 完整视频 + 正文文案 |
| B站/西瓜 | 横版 | 4:3 封面 |

## 自检清单

- [ ] 文案里的每句英文都能在课程 JSON 里找到
- [ ] 封面文字 ≤ 3 个元素，数字/结果前置
- [ ] 标题含数字，正文首屏（前 3 行）能看出"这跟我有关"
- [ ] 标签同时含泛词和精准词
- [ ] 有明确的下一步动作（收藏 / 扣关键词 / 关注追更）
